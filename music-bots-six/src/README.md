# Six Room Arabic Music Bots

هذا المشروع يشغّل حتى ستة بوتات Discord من نفس التطبيق. كل بوت مرتبط بروم صوتي محدد، ويستجيب للأوامر العربية داخل السيرفر المحدد في `GUILD_ID`.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `ش اسم الأغنية` | البحث عن الأغنية في SoundCloud وتشغيلها |
| `ش https://soundcloud.com/...` | تشغيل رابط SoundCloud مباشر |
| `وقف` | إيقاف مؤقت |
| `كمل` | استئناف التشغيل |
| `س` | تخطي الأغنية |
| `صوت 100` | ضبط الصوت من 0 إلى 130 |
| `قدم 20` | إعادة التشغيل من الثانية 20 |
| `قائمة` | عرض قائمة الانتظار |
| `انهاء` | إيقاف التشغيل وتفريغ القائمة |

## الإعداد

أنشئ تطبيقات Bot الستة من Discord Developer Portal، وفعّل لكل تطبيق `Message Content Intent` و`Guild Voice States`. ادعُ كل بوت إلى السيرفر نفسه مع صلاحيات قراءة القنوات، إرسال الرسائل، تضمين الروابط، والاتصال والتحدث في الروم الصوتي الخاص به.

انسخ `.env.example` إلى `.env` وضع `GUILD_ID` الصحيح وتوكن كل بوت في المتغير المقابل. لا تنشر ملف `.env` ولا ترسل التوكنات لأي شخص.
